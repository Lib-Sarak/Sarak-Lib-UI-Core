# Propósito

Este arquivo é um **log de acompanhamento, append-only**, de toda execução de spec feita a partir de `specs/plan/`. Não é uma spec de feature — é o registro histórico que permite a um agente sênior avaliar rapidamente **o que** foi feito, **como**, e **quando**, sem reconstruir o raciocínio lendo todo o diff.

**Regra de Ouro:** toda vez que um agente terminar de executar uma spec (total ou parcialmente) e atualizar o status dela em `specs/plan/*.md`, ele **deve**, no mesmo momento, adicionar uma entrada nova aqui — no topo da seção "Entradas", mais recente primeiro. Nunca editar ou apagar uma entrada já escrita por outra execução; só adicionar.

> **Nota de higiene (2026-07-17):** este log foi COMPACTADO no replanejamento da onda "Renderizador Genérico" — as entradas detalhadas de 2026-07-11/12 (sub-plano Design Agent, hoje cancelado) foram condensadas na entrada "Histórico condensado" abaixo. O texto integral permanece no histórico git deste arquivo (commits até 2026-07-17).
