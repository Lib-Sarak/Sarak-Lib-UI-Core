# Validação da Instalação do Sarak UI Core

- [ ] A biblioteca foi adicionada no gerenciador de pacotes do sistema (ex: `package.json`).
- [ ] O componente `SarakUIProvider` envolve a raiz da aplicação frontend.
- [ ] O arquivo `sarak.css` (ou `sarak-base.css`) foi importado na raiz.
- [ ] O sistema consumidor chama a função nativa `setupUIDatabase` (Node) ou `setup_ui_db` (Python) em seu processo de startup.
- [ ] Para projetos Node.js, a URL do banco (`DATABASE_URL`) está sendo passada corretamente para a bridge.
- [ ] As correções realizadas foram registradas no log da sessão?
